# Полная структура класса IOPoint и всех подклассов

## 📋 Полная иерархическая структура

```
IOPoint - Точка ввода-вывода в системе автоматизации
│
├── Id : Identification? - Идентификационные данные точки
│   ├── Code : int? - Порядковый номер строки в списке (из колонки "Код")
│   ├── Area : int? - Номер технологической установки/зоны (географическое расположение)
│   ├── Title : string? - Номер установки/зоны (функциональное наименование)
│   ├── Loop : string? - Технологический контур (связывает точки одного процесса)
│   ├── iLoop : string? - Вложенный субконтур (детализация внутри основного контура)
│   ├── Loop_pc : string? - Технологический контур (технологическое разделение)
│   ├── Tag : string? - Уникальный тег устройства (главный идентификатор)
│   ├── ParsedTag : InstrumentTag? - Распарсенный тег (структурированные компоненты)
│   │   ├── Area : string? - Код площадки/завода (0-6 ЦИФР!)
│   │   ├── DeviceClass : string? - Класс прибора (1-5 букв A-Z)
│   │   ├── Loop : string? - Номер технологического контура (1-5 цифр)
│   │   ├── TagNumber : string? - Порядковый номер прибора (0-3 ЦИФРЫ!)
│   │   ├── Suffix : string? - Суффикс (модификатор прибора, 0-3 символа)
│   │   ├── FullTag : string? - Исходный тег в полном виде
│   │   └── Separator : char? - Определенный разделитель (если отсутствовал - null)
│   ├── Tag_Prc : string? - Технологический тег устройства (для технологических схем)
│   ├── Service : string? - Технологическое описание сигнала (на русском языке)
│   ├── InstrumentType : string? - Тип прибора/устройства (на русском языке)
│   ├── Service_Eng : string? - Технологическое описание сигнала (на английском языке)
│   ├── InstrumentTypeEng : string? - Тип прибора/устройства (на английском языке)
│   ├── Sys : SystemType? - Тип системы управления (DCS/SCS/GDS)
│   │   └── enum SystemType
│   │       ├── DCS - Распределенная система управления (основной техпроцесс)
│   │       ├── SCS - Система безопасности / SIS (Safety Instrumented System)
│   │       └── GDS - Система обнаружения газа (Gas Detection System)
│   ├── IO_Type : string? - Тип сигнала ввода-вывода (DO - дискретный выход, AI - аналоговый вход)
│   ├── Controller : string? - Имя контроллера (FCS, SCS, GDS) в системе управления
│   ├── Location : string? - Место установки оборудования (Field - полевое, SIS - система безопасности, MCC - шкаф мотор-контроллеров)
│   └── Pid : string? - Номер P&ID (Piping and Instrumentation Diagram) для привязки к схеме
│
├── Signal : Signal? - Технологические параметры сигнала
│   ├── Service : string? - Технологическое описание сигнала (полное наименование)
│   ├── InstType : string? - Тип прибора/устройства (полное наименование)
│   ├── Sys : string? - Идентификатор системы управления (FCS, SCS, GDS)
│   ├── SysType : SystemType? - Тип системы управления (DCS/SCS/GDS)
│   ├── Pid : string? - Номер листа P&ID для привязки к технологической схеме
│   ├── Loc : string? - Место установки/подключения сигнала (Field, SIS, MCC, AUX, GDS)
│   ├── SigType : string? - Тип сигнала (I/O Type): DOR-P, DIR(I)-NAMUR, AIR-LP и др.
│   ├── Ex : string? - Взрывозащита оборудования: Ex.d (взрывонепроницаемая), Ex.i (искробезопасная), "-" (не требуется)
│   ├── SubSys : string? - Идентификатор подсистемы (например, номер стойки или шкафа)
│   └── Aux : string? - Вспомогательный прибор (сигнальный изолятор, преобразователь)
│
├── Ranges : Ranges? - Диапазоны измерений и уставки аварийной сигнализации
│   ├── Primary : Range? - Основной диапазон измерения (используется для масштабирования сигнала)
│   │   ├── Min : decimal? - Минимальное значение диапазона (по умолчанию 0)
│   │   ├── Max : decimal? - Максимальное значение диапазона (по умолчанию 100)
│   │   └── Unit : string? - Единица измерения (мм, kPa, ℃, %VOL, μS/cm, PH)
│   ├── Secondary : Range? - Вторичный диапазон измерения (для пересчета в другие единицы)
│   │   ├── Min : decimal? - Минимальное значение вторичного диапазона
│   │   ├── Max : decimal? - Максимальное значение вторичного диапазона
│   │   └── Unit : string? - Единица измерения вторичного диапазона
│   ├── Alarms : Alarm? - Уставки аварийной сигнализации (для предупреждений и отключений)
│   │   ├── LL : decimal? - Авария "Нижний-Нижний" (критичный низкий уровень, остановка процесса)
│   │   ├── LL2 : decimal? - Второй "Нижний-Нижний" (дополнительный критичный уровень)
│   │   ├── L : decimal? - Предупреждение "Нижний" (внимание оператора, низкий уровень)
│   │   ├── H : decimal? - Предупреждение "Верхний" (внимание оператора, высокий уровень)
│   │   ├── HH : decimal? - Авария "Верхний-Верхний" (критичный высокий уровень, остановка процесса)
│   │   └── HH2 : decimal? - Второй "Верхний-Верхний" (дополнительный критичный уровень)
│   └── AlarmUnit : string? - Единица измерения для уставок (если отличается от Primary)
│
├── Cable : Cable? - Кабельное хозяйство (физическое подключение сигнала)
│   ├── Id : string? - Уникальный идентификатор кабеля (по проектной документации)
│   ├── Desc : string? - Описание кабеля (назначение, куда подключен)
│   ├── Type : string? - Полный тип кабеля (количество и сечение жил, изоляция, оболочка)
│   ├── Desig : string? - Обозначение кабеля по проектной документации
│   ├── From : string? - Начальная точка кабеля (откуда идет, например "2701-S-JB-D018")
│   ├── To : string? - Конечная точка кабеля (куда идет, например "SIS")
│   ├── Len : int? - Длина кабеля в метрах (целое число)
│   ├── Color : string? - Цвет кабеля или цвет изоляции жилы (BK - черный, BU - синий)
│   ├── Pair : int? - Номер пары или жилы внутри кабеля
│   ├── Note : string? - Дополнительное примечание по кабелю (изменения, особые условия)
│   ├── TitleAker : string? - Наименование кабеля по документации Aker Solutions
│   ├── Drum : string? - Номер барабана для учета кабеля при монтаже
│   └── Volt : string? - Напряжение питания для активных устройств (если применимо)
│
├── Hardware : Controller? - Оборудование контроллера (привязка к аппаратным средствам)
│   ├── CableTecon : string? - Идентификатор кабеля по документации TECON (подрядчик)
│   ├── Mcc : string? - Номер подстанции MCC (Motor Control Center) для моторных сигналов
│   ├── CtrlCab : string? - Идентификатор шкафа управления (Control Cabinet)
│   ├── MarshCab : string? - Идентификатор шкафа маршаллинга (Marshalling Cabinet)
│   ├── Cpu : string? - Тег процессора (CPU) в системе управления
│   ├── Chassis : Chassis? - Шасси (стойка) контроллера
│   │   ├── Main : string? - Идентификатор основного шасси (стойки)
│   │   └── Red : string? - Идентификатор резервного шасси (для горячего резервирования)
│   └── Module : Module? - Модуль ввода-вывода (I/O Module)
│       ├── Slot : string? - Номер слота основного модуля (например, A11, A13)
│       ├── SlotRed : string? - Номер слота резервного модуля (например, A12, A14)
│       ├── Main1 : string? - Идентификатор основного модуля 1 (для двухканальных модулей)
│       ├── Main2 : string? - Идентификатор основного модуля 2 (для двухканальных модулей)
│       ├── Red1 : string? - Идентификатор резервного модуля 1
│       ├── Red2 : string? - Идентификатор резервного модуля 2
│       ├── Ch : int? - Номер канала внутри модуля (например, 20, 21)
│       └── Type : string? - Тип модуля ввода-вывода (DI32, DO32P, AI16H и др.)
│
└── Rev : Revision? - Управление версиями и метаданными
    ├── No : int? - Номер ревизии (версия данных)
    ├── Desc : string? - Подробное описание изменений в текущей ревизии
    ├── Package : string? - Оборудование поставщика (пакетное оборудование, например "SDPump", "VINCI")
    ├── Field1 : string? - Дополнительное поле 1 (может содержать имя поставщика, например "Xinhui")
    ├── Field2 : string? - Дополнительное поле 2
    ├── Doc : string? - Ссылка на техническую документацию (номер документа, статус)
    ├── Aker : string? - Ревизия от Aker Solutions (если применимо)
    ├── FileName : string? - Имя файла-источника данных (откуда загружена информация)
    ├── Author : string? - Автор, создавший запись (ответственный за ввод данных)
    ├── DateEntered : DateTime? - Дата и время ввода информации в систему
    └── RowNumber : int? - Номер строки в документе-источнике (для обратного прослеживания)
```

## 📋 Детальное описание всех классов

### 1. IOPoint (Точка ввода-вывода)

Главный класс, объединяющий все аспекты точки ввода-вывода в системах автоматизации.

| Свойство | Тип | Описание | Обязательность |
|:---|:---|:---|:---|
| `Id` | `Identification?` | Идентификационные данные точки (тег, контур, номер, описания) | Нет |
| `Signal` | `Signal?` | Технологические параметры сигнала (тип прибора, место установки, взрывозащита) | Нет |
| `Ranges` | `Ranges?` | Диапазоны измерений и уставки аварийной сигнализации | Нет |
| `Cable` | `Cable?` | Данные о кабельном хозяйстве (кабель, цвет, длина, маршрут) | Нет |
| `Hardware` | `Controller?` | Привязка к оборудованию контроллера (шкафы, стойки, модули, каналы) | Нет |
| `Rev` | `Revision?` | Информация о версиях и ревизиях документации | Нет |

### 3. InstrumentTag (Парсер тегов)

Парсер промышленных тегов с автоматическим разбором структуры.

| Свойство | Тип | Описание | Пример | Ограничения |
|:---|:---|:---|:---|:---|
| `Area` | `string?` | Код площадки/завода (технологическая установка) | `"2701"` | **0-6 ЦИФР!** |
| `DeviceClass` | `string?` | Класс прибора (тип устройства по функциональному назначению) | `"XZY"` | 1-5 букв A-Z |
| `Loop` | `string?` | Номер технологического контура (связывает приборы одного процесса) | `"10101"` | 1-5 цифр |
| `TagNumber` | `string?` | Порядковый номер прибора в контуре (уникальный идентификатор) | `"01"` | 0-3 ЦИФРЫ! |
| `Suffix` | `string?` | Суффикс (модификатор прибора: резервный, основной, часть системы) | `"A"` | 0-3 буквы/цифры |
| `FullTag` | `string?` | Исходный тег в полном виде (для обратного прослеживания) | `"2701-XZY-10101A"` | - |
| `Separator` | `char?` | Определенный разделитель (автоматически определяется при парсинге) | `'-'` | - |

**Примеры парсинга:**

| Тег | Area | DeviceClass | Loop | TagNumber | Suffix |
|:---|:---|:---|:---|:---|:---|
| `2701-XZY-10101A` | `"2701"` | `"XZY"` | `"10101"` | `"01"` | `"A"` |
| `123456-PDT-01001A` | `"123456"` | `"PDT"` | `"010"` | `"01"` | `"A"` |
| `42-FT-123` | `"42"` | `"FT"` | `"123"` | `""` | `""` |
| `P-9999` | `""` | `"P"` | `"9999"` | `""` | `""` |
| `123456PDT01001A` | `"123456"` | `"PDT"` | `"010"` | `"01"` | `"A"` |
| `TEMP-12345` | `""` | `"TEMP"` | `"12345"` | `""` | `""` |

### 4. Signal (Технологические параметры сигнала)

Детальная информация о сигнале: тип прибора, взрывозащита, тип сигнала.

| Свойство | Тип | Описание | Пример |
|:---|:---|:---|:---|
| `Service` | `string?` | Технологическое описание сигнала (полное наименование) | `"Styrene Inlet Switch Valve of 2701-TK-1205A"` |
| `InstType` | `string?` | Тип прибора/устройства (полное наименование) | `"Solenoid valve"` |
| `Sys` | `string?` | Идентификатор системы управления (FCS, SCS, GDS) | `"2000-S-SC-B01"` |
| `SysType` | `SystemType?` | Тип системы управления (DCS/SCS/GDS) | `DCS` |
| `Pid` | `string?` | Номер листа P&ID для привязки к технологической схеме | `"2490156-1401-PR007-0101A"` |
| `Loc` | `string?` | Место установки/подключения сигнала (Field, SIS, MCC, AUX, GDS) | `"Field"` |
| `SigType` | `string?` | Тип сигнала (I/O Type): DOR-P, DIR(I)-NAMUR, AIR-LP и др. | `"DOR-P"` |
| `Ex` | `string?` | Взрывозащита оборудования: Ex.d (взрывонепроницаемая), Ex.i (искробезопасная), "-" (не требуется) | `"Ex.d"` |
| `SubSys` | `string?` | Идентификатор подсистемы (например, номер стойки или шкафа) | `"RACK-01"` |
| `Aux` | `string?` | Вспомогательный прибор (сигнальный изолятор, преобразователь) | `"Isolator-01"` |

### 5. Ranges (Диапазоны и уставки)

Диапазоны измерений и уставки аварийной сигнализации.

| Свойство | Тип | Описание |
|:---|:---|:---|
| `Primary` | `Range?` | Основной диапазон измерения (используется для масштабирования сигнала) |
| `Secondary` | `Range?` | Вторичный диапазон измерения (для пересчета в другие единицы) |
| `Alarms` | `Alarm?` | Уставки аварийной сигнализации (для предупреждений и отключений) |
| `AlarmUnit` | `string?` | Единица измерения для уставок (если отличается от Primary) |

#### 5.1. Range (Диапазон)

| Свойство | Тип | Описание | Пример |
|:---|:---|:---|:---|
| `Min` | `decimal?` | Минимальное значение диапазона (по умолчанию 0) | `0` |
| `Max` | `decimal?` | Максимальное значение диапазона (по умолчанию 100) | `100` |
| `Unit` | `string?` | Единица измерения (мм, kPa, ℃, %VOL, μS/cm, PH) | `"%"` |

#### 5.2. Alarm (Уставки аварийной сигнализации)

| Свойство | Тип | Описание | Пример |
|:---|:---|:---|:---|
| `LL` | `decimal?` | Авария "Нижний-Нижний" (критичный низкий уровень, остановка процесса) | `10` |
| `LL2` | `decimal?` | Второй "Нижний-Нижний" (дополнительный критичный уровень) | `5` |
| `L` | `decimal?` | Предупреждение "Нижний" (внимание оператора, низкий уровень) | `20` |
| `H` | `decimal?` | Предупреждение "Верхний" (внимание оператора, высокий уровень) | `80` |
| `HH` | `decimal?` | Авария "Верхний-Верхний" (критичный высокий уровень, остановка процесса) | `90` |
| `HH2` | `decimal?` | Второй "Верхний-Верхний" (дополнительный критичный уровень) | `95` |

**Иерархия уровней:**
```
LL2 ← LL ← L ←─── НОРМА ───→ H → HH → HH2
(крит) (крит) (пред)          (пред) (крит) (крит)
```

### 6. Cable (Кабельное хозяйство)

Информация о физическом подключении сигнала.

| Свойство | Тип | Описание | Пример |
|:---|:---|:---|:---|
| `Id` | `string?` | Уникальный идентификатор кабеля (по проектной документации) | `"CBL-001"` |

## ✅ Ключевые особенности

1. **Все свойства nullable** — гибкость при работе с неполными данными
2. **Автоматический парсинг тегов** — через `InstrumentTag` (Area до 6 цифр!)
3. **TagNumber — только цифры** — строгое правило парсинга
4. **Двойные аварийные уровни** — `LL2` и `HH2` для дополнительной критической сигнализации
5. **Полная иерархия** — от общего `IOPoint` до детальных подклассов
6. **Поддержка DCS/SCS/GDS** — различные типы систем управления
7. **Метаданные источника** — `FileName`, `Author`, `DateEntered`, `RowNumber` для аудита
8. **Многоязычная поддержка** — описания на русском и английском языках
9. **Технологический тег** — `Tag_Prc` для технологических схем
